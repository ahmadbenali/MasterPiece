# Wise static homepage showcase

Open `index.html` directly in a browser. No build, server, accounts or data storage are required. HTML, Bootstrap 5.3, CSS and vanilla JavaScript; fonts and artwork are local.

Personal and Platform open on desktop hover, with a sliding white menu, active pill and a blurred/dimmed backdrop. The menus support keyboard focus and Escape. Touch navigation uses expandable lists.

Presentation motion follows the supplied recording: staggered hero entrance, scroll reveals, stacked rate panels, a moving currency strip, a fanned review deck and looping artwork. Reduced-motion preferences suppress decorative motion.

The transfer card is a fixed visual sample. Currency labels and flags may be changed cosmetically, but there are no calculations, transactions, API requests, persistence or account workflows. Dialogs only display sample information. Country and language selection is cosmetic. Some informational links point to Wise's public website.

Reference: Wise's Jordan homepage and the screenshots and recording supplied on 6 October 2026. This independent recreation is not affiliated with Wise. Reference fonts and artwork belong to their owners; review copy is illustrative.
