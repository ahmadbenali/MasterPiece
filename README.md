# Master Piece
Master Piece project for orange code academy.

# About the project
<strong>North Bank is a bank system management with lots of features Mentioned below </strong>

## Features:
1. <strong>🔴 Multi LLM Fraud detection </strong>: Show the fraud classifier's score alongside assessments from three LLMs. Analysts can compare their reasoning, inspect the transaction evidence, and see where models disagree. Add an investigation timeline and allow analysts to record a final decision with supporting evidence.
2. <strong style="color🟢"> 🟢Smart spending insights </strong>: Automatically categorize transactions into food, shopping, transport, bills, and other expenses. Show monthly charts, spending comparisons, and alerts when a customer approaches their budget.
3. <strong>🟢Subscription and bill manager </strong>: Detect recurring payments, display upcoming bills on a calendar, and notify customers before subscriptions renew. Customers can also set reminders or schedule payments.
4. <strong>🔴Personal security center </strong>: Show recent login activity, recognized devices, active sessions, and suspicious activity alerts. Customers can revoke sessions, update security settings, or temporarily lock their account.
5. <strong>🔴Live fraud monitoring center. </strong>
6. <strong>🟢Customer accounts, transfers, and transaction history.</strong>
7. <strong>🟢Customer fraud confirmation</strong>: When the fraud system flags a transaction, the customer receives an alert asking whether they recognize it.
8. <strong>🟢Where to find ATM and working hours. </strong>
